# Query Expansion Coursework

RM3 and DMM feedback-model scripts, including a second DMM parameter variant.

## Contribution and provenance

The three HW3 scripts preserve the submitted feedback computations and their course-facing interfaces.

## Running

Supply the original `hw3_utils` helper and course index/query data before running the scripts. Inspect their imports for the required runtime.

## Evidence and limits

`hw3_utils` was not found in the source tree. These files are incomplete as a standalone runnable package; no replacement helper or benchmark result has been invented.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
