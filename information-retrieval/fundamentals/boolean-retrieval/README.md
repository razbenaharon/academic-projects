# Boolean Retrieval

An inverted index and Boolean query processing over document text.

## Contribution and provenance

`boolean_retrieval.py` contains the submitted index/query implementation; its original identifier-bearing filename has been replaced.

## Running

Inspect the InvertedIndex interface in the source and supply a document collection through the original course harness. Dependencies are listed in the source imports.

## Evidence and limits

The corpus and grading harness are not included. This is an educational Boolean index, distinct from the hybrid Wikipedia pipeline.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
