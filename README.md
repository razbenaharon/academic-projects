# Academic Projects

This repository contains a curated collection of my academic projects and coursework, with a primary focus on Machine Learning, Deep Learning, Artificial Intelligence, and Data Engineering. The projects demonstrate a progression from foundational software engineering and algorithms to advanced AI research and distributed systems.

## Highlights & Selected Works

While the repository contains many assignments and exercises, the following projects represent some of the most significant engineering and algorithmic challenges I tackled:

* **[Active Learning](./machine-learning/active-learning/)**: An implementation of active learning strategies, demonstrating the ability to efficiently query data to train models with minimal labels.
* **[Surgical Tool Detection](./computer-vision/surgical-tool-detection/)**: A computer vision deep learning model designed to detect and localize surgical tools in medical imagery.
* **[Entity Matching](./machine-learning/entity-matching/)**: A data integration pipeline focusing on resolving and matching entities across different schemas and datasets.
* **[Adversarial and Contrastive Learning](./deep-learning/adversarial-and-contrastive-learning/)**: Exploration of deep learning robustness using FGSM adversarial attacks, as well as representation learning using SimCLR.
* **[Wikipedia Hybrid Retrieval](./information-retrieval/wikipedia-hybrid-retrieval/)**: An advanced IR system combining sparse (BM25) and dense (vector) retrieval methods to search over Wikipedia.

## Directory Structure and Skills Map

The repository is organized by subject area rather than chronologically, allowing for easier navigation by topic:

* **[Machine Learning](./machine-learning/)**: Supervised and unsupervised learning from scratch (KNN, Perceptron, K-Means), Random Forests with Spark NLP, and recommendation systems using UCB.
* **[Deep Learning](./deep-learning/)**: Core neural networks, CNNs, RNNs/LSTMs for sentiment analysis, Variational Autoencoders (Flower VAE), Contrastive Learning (SimCLR), and Graph Neural Networks (GraphSAGE).
* **[Computer Vision](./computer-vision/)**: Object detection and medical imaging analysis.
* **[Information Retrieval](./information-retrieval/)**: Search engine fundamentals, inverted indices, query expansion (RM3/DMM), dynamic vector indices, and hybrid search.
* **[AI and Decision Making](./ai-and-decision-making/)**: Heuristic search, stochastic planning (MDPs, Value Iteration), agent-based models (FoodFlow), influence maximization in networks, and auction simulation (GSP).
* **[Statistics](./statistics/)**: Exploratory data analysis, statistical inference, regression, ANOVA, and Bootstrap methods.
* **[Engineering Foundations](./engineering-foundations/)**: 
  * *Data Engineering*: Spark, MapReduce, ETL pipelines, and distributed data analysis.
  * *Databases*: SQL queries, schemas, views, and a Django web application.
  * *Software & Algorithms*: Java OOP projects (Search, Generics, Trees) and C programming (games).
  * *Systems*: Bitwise operations and OS kernel development (xv6).

## Notes

- Some projects, especially those involving Deep Learning or Spark, depend on specific course datasets or external platforms (like Databricks) and may require modification to run locally.
- Sensitive data, IDs, and large model weights have been omitted from this repository.
