# GraphSAGE on Cora

Convert node features and citation edges for graph learning, create bidirectional edges and implement GraphSAGE with PyTorch Geometric.

## Contribution and provenance

`gnn.py` is my implementation of the supplied section-B interface. The active-learning implementation in the same original submission is stored once under machine-learning.

## Running

Python with numpy, pandas, torch and torch-geometric. Import `gnn.py` from a compatible course harness with Cora nodes/edges and the expected mappings.

## Evidence and limits

The harness/dataset are absent and torch-geometric was unavailable in the validation environment; this file received syntax checks, not an end-to-end training evaluation.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
