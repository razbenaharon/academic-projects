# Deep Learning

This directory contains neural network models, ranging from fundamental implementations to advanced architectures like GraphSAGE and Contrastive Learning.

## Projects
* **[Neural Network Fundamentals](./neural-network-fundamentals/)**:
  * **NumPy MLP & CNN**: Forward and backpropagation from scratch, and PyTorch CNN for cat classification.
* **[Sentiment Analysis](./sentiment-analysis/)**: RNN/LSTM for IMDB sentiment classification.
* **[Adversarial and Contrastive Learning](./adversarial-and-contrastive-learning/)**: CNN on SVHN, FGSM adversarial attacks, and SimCLR (NT-Xent).
* **[Flower VAE](./flower-vae/)**: Encoder/Decoder Variational Autoencoder, reparameterization, and image generation.
* **[GraphSAGE](./graphsage/)**: Graph Representation Learning.
