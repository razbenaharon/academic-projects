# Neural Network Fundamentals

The original combined assignment is split by its existing question boundary:

- [Manual MLP](manual-mlp/): sigmoid/softmax and manually computed gradients using PyTorch tensors.
- [Cat CNN](cat-classification-cnn/): a convolutional classifier and its training notebook.

The MLP is not implemented with NumPy. Shared course instructions are credited in each notebook;
standalone model classes are stored once and imported by the corresponding notebooks.
