# NumPy K-means

Feature scaling, centroid updates and cluster visualization on London bicycle-use data; the driver compares k=2, 3 and 5.

## Contribution and provenance

`clustering.py` implements clustering; `data.py` and `main.py` provide preprocessing and experiments within the coursework structure.

## Running

Python with numpy, pandas and matplotlib. Place the course `london.csv` in this directory and run `python main.py`.

## Evidence and limits

The dataset is excluded. No new clustering scores were measured during migration.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
