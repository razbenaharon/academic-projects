# Coupon Recommendation and Online Learning

Sparse regularized least squares and a latent-factor variant for ratings, followed by budget-constrained online decisions using UCB.

## Contribution and provenance

`HW2.py` implements the assignment stages and course-facing functions.

## Running

Python with numpy, pandas and scipy. Call `solve_stage_a(train_path, test_path, coupon_info_path, output_dir)` with the documented CSV schemas; use the original course simulation interface for the online stage.

## Evidence and limits

The course data and online simulator are absent. Distinguish offline error from online reward; neither was rerun for publication.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
