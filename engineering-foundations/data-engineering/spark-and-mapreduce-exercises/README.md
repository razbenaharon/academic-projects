# Spark and MapReduce Coursework

Grouped distributed-data exercises: MapReduce TV analytics, PySpark K-means, three labs and a TV audience analysis project.

## Contribution and provenance

Submitted code/notebooks are grouped by assignment; notebook task text and starter interfaces came from the course.

## Running

Use Spark/Databricks and the course input datasets. MapReduce scripts additionally require mrjob. Update storage paths before running.

## Evidence and limits

Data are excluded and distributed jobs were not executed locally. Starter naming does not mean a file has no implementation; inspect its code. Cross-reference the larger household project rather than duplicating it.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
