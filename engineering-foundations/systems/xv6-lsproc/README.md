# xv6 lsproc Patch

A coursework patch adding process-listing functionality through xv6 kernel/user interfaces.

## Contribution and provenance

`HW_04.patch` is the preserved submission. The xv6 base project is external course scaffolding.

## Running

Obtain the matching course xv6 revision and inspect `git apply --check HW_04.patch` before applying the patch to a disposable checkout.

## Evidence and limits

The exact base revision was not supplied. Patch application, boot and syscall behavior are unverified; this is a patch artifact, not a complete OS repository.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
