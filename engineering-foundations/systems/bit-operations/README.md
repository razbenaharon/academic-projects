# Bit Operations in C

Three bit-level operations: bitAnd, getByte and logicalShift.

## Contribution and provenance

`hw1.c` preserves the small submitted functions. This is grouped foundational coursework, not a standalone systems project.

## Running

Compile with `gcc -std=c11 -Wall -Wextra -c hw1.c`. The empty main function is not an automated test suite.

## Evidence and limits

Compilation does not establish correctness across every signed/shift edge case. Review the assignment's machine-model assumptions.
