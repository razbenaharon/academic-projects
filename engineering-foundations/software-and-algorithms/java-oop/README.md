# Java OOP and Algorithms Coursework

Battleship; sliding-puzzle search; functions/derivatives/Taylor/Newton/bisection; generic stacks and playlists; binary-tree queries.

## Contribution and provenance

Assignment directories preserve submitted implementations together with course interfaces/test drivers. Each Main class belongs to its own assignment.

## Running

Install a JDK. Compile one directory at a time with `javac *.java` and run `java Main` within that directory. Do not compile all assignments as one default-package project.

## Evidence and limits

A JDK was unavailable during migration, so Java compilation and runtime behavior remain unverified. Some Main classes are supplied test drivers, not independent projects.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
