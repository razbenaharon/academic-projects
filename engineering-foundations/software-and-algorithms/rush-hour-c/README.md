# Rush Hour in C

Board representation, move handling and gameplay for the Rush Hour puzzle.

## Contribution and provenance

`rush_hour.c` is the personal submission selected from the original coursework directory.

## Running

With a C compiler, run `gcc -std=c11 -Wall -Wextra rush_hour.c -o rush_hour`, then execute the program and follow its input prompts.

## Evidence and limits

Compilation is checked; interactive gameplay is not exhaustively tested. Other C exercises with uncertain authorship were not imported.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
