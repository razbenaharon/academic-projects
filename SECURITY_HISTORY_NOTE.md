# Legacy Repository History Note

The curated `academic-projects` repository was migrated from clean current working trees and intentionally does not import the Git histories of the legacy standalone academic repositories.

This matters because some legacy histories contained information that should not be copied into a new public portfolio, including student identifiers and, in the case of Match-Point, credentials that were historically committed.

The current `academic-projects` repository is the canonical public academic portfolio. Archived source repositories should be treated as historical records, not as the preferred public entry point.

Important: removing a credential from Git or making a repository private does not revoke that credential. Provider-side rotation remains required for anything that was previously exposed publicly.
