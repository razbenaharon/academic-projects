# Stochastic Wizard Planning

Wizard agents with state transitions, rewards and value iteration under stochastic outcomes.

## Contribution and provenance

`ex3.py` contains my agents. Checker/input/utility files provide course evaluation context and additional local cases.

## Running

Run `python check.py` from this directory; review `check_tests.py` for the additional cases.

## Evidence and limits

Runtime depends on the size of the state space. No new aggregate score or optimality claim is presented.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
