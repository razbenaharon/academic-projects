# Partial-Observability Agent

A Gringotts agent selecting actions from partial information about its environment.

## Contribution and provenance

`ex2.py` contains my agent. `checker.py`, `inputs.py` and `utils.py` are the supplied evaluation/framework context; redundant original starter copies are omitted.

## Running

Run `python checker.py` from this directory. The course checker defines observation/action contracts.

## Evidence and limits

The selected source version is preserved. No claim is made that it is the best of every historical duplicate submission.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
