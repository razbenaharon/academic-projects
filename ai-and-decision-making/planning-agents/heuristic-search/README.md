# Heuristic Search Agent

Harry Potter state-space planning with successor generation and a heuristic.

## Contribution and provenance

`ex1.py` is my submission. `check.py`, `problems.py`, `search.py` and `utils.py` support the supplied course environment and search framework.

## Running

Run `python check.py` from this directory with Python. Inspect the checker time limits before running larger cases.

## Evidence and limits

The checker is not a proof of heuristic admissibility or optimality. Personal submission IDs are placeholder values in the public copy.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
