# GSP Bidding Agents

Policies and variant comparisons for a generalized second-price auction simulation.

## Contribution and provenance

`id.py` is the submission; `benchmark_variants.py` contains experiment variants. `server.py`, `CONSTANTS.py` and dummy agents are course simulation context, not all my independent implementations. Document-generation scripts are omitted.

## Running

Inspect `test_submission.py` and the server entry point before running. Use the local course simulation; do not connect to an external submission service. Python dependencies are visible in the imports.

## Evidence and limits

Placeholder submission identifiers are retained only for interface compatibility. No new auction reward benchmark was measured.

Imported coursework outputs and personal submission metadata have been removed from the public copy. The original OneDrive materials were not edited.
