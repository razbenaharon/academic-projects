# Hotel Booking Statistical Analysis

Four submitted notebooks, grouped by their original analysis task:

- [Exploratory analysis](exploratory-analysis/analysis.ipynb): descriptive statistics and visual exploration.
- [Statistical inference](statistical-inference/analysis.ipynb): inference and distributional reasoning.
- [Regression and model selection](regression-and-model-selection/analysis.ipynb): OLS, Logit, interactions, ANOVA and AIC/BIC selection.
- [Bootstrap](bootstrap/analysis.ipynb): bootstrap estimates and likelihood-based analysis.

Use a Python notebook environment with numpy, pandas, scipy, statsmodels, matplotlib and seaborn.
Supply the original hotel-booking CSV and update each notebook's input path before running.
The notebooks mix course prompts with submitted code and written answers. Embedded submission
images and execution outputs were removed; historical answers are not newly rerun measurements.

These are foundations for [machine learning](../../machine-learning/), stored here once.
